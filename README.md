# Artifacts

This is a position paper. It introduces no new method, dataset, model, or
experimental result, and there are accordingly no code or data artifacts to
release beyond the manuscript itself.

The paper's argument rests entirely on sources that are already public: the
five works audited in the paper, the deployment artifact examined in Section
VII-A, and the literature cited throughout. All cited sources are identified
by venue, DOI, or arXiv identifier in the references.

Every claim-level score reported in Table II is accompanied in Section VII-B
by the quotation from the source on which it rests, so the audit can be
reproduced from the published sources without additional material from the
authors.
